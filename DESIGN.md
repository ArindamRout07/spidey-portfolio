# Visual Personality

The portfolio should feel:

- Cinematic
- Editorial
- Experimental
- Technical
- Premium
- Minimal
- Slightly mysterious

It should NOT feel:

- Corporate
- Template-based
- Generic
- Gaming-heavy
- Neon-heavy
- Over-animated

# Layout

Use:

- strong negative space
- asymmetric compositions
- oversized typography
- editorial grids
- intentional whitespace
- large visual anchors

Avoid:

- repetitive card grids
- excessive rounded containers
- excessive shadows
- generic dashboard layouts

---

# Motion

Primary animation system:

GSAP + ScrollTrigger

Entrance animations:

- clip-path reveals
- staggered movement
- 3D rotation
- controlled parallax

Ambient animations:

- subtle floating
- slow rotation
- gentle swinging
- breathing glow

Physics:

Elastic easing for hanging elements.

Ambient:

Sine.inOut.

---

# Interaction Principles

Hover effects should be:

- fast
- subtle
- responsive
- purposeful

Desktop may use:

- custom cursor
- magnetic buttons
- image reveals
- subtle parallax

Mobile should simplify these interactions.

---

# 3D

3D should be used to create:

- depth
- storytelling
- interaction
- visual identity

3D should never exist simply
because it looks technically impressive.

---

# Accessibility

Respect:

prefers-reduced-motion

Maintain:

- readable typography
- sufficient contrast
- keyboard accessibility
- touch-friendly interactions
